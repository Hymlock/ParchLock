## Minimal design
New exact-fact display descriptor `lockedObservation: { attribute: 8, objects: [52] }` on Moonmist's executable fact. This descriptor owns a raw display observation only. No Moonmist attributeMap.locked/lockable entry and no generic attrs.locked field is added.

AttributeSchema.lockedObjectStatus resolves either the existing lockedStatusObjects + mapped LOCKED path (unchanged LH behaviour) or a validated lockedObservation descriptor. A fact declaring both paths is invalid (fail closed, never fall back across an ambiguous descriptor). Descriptor must have exactly attribute/objects, integer attribute in v3..5 bit range, nonempty unique integer objects wholly within the true object frontier; queried owner must belong. Preserve exact-executable/stable-header ownership and confirmed validated ZIL family, exclude Inform names, and reread live current RAM. Do not call measuredFlagOwner('locked') for this alternate path because that helper intentionally requires map/capability ownership; the new descriptor is the explicit measured display owner, not a generic profile fallback. Invalid descriptor must never use a guessed bit/profile.

Actionable and UI continue using the existing D5 current-memory/generation/digest/stamped-object/scoped-primary-view predicates and existing layout. No new command path, no new status from projection/tool rows. Existing LH fact shape stays unchanged. Frontdoor120 and room/EARRING/GO/secret-door carriers are excluded until separately useful and qualified; no arbitrary expansion from same bit.

ExitCalibrator, MapIdentity, Navigator, ActionSynth rules and generic attribute maps receive no new semantic inputs. Focused checks must prove Moonmist DEXIT/routeBlocked are unchanged and mapped bit remains absent. Raw display never means impassable, lockable or a key requirement.
