# Games included with ParchLock

> **Public build:** this distribution bundles only the Z-machine stories in release\public-games.txt. Glulx titles listed here are not bundled; Glulx stories you add yourself play with story text and input only (no map, underlines or Equipment).


The ParchLock application is licensed under the GNU GPL version 3 (see `LICENSE`). **That licence does not cover the games listed here.** Each game is a separate work that remains the copyright of its author, and is included only because its author's licence or terms permit free, unmodified redistribution.

- Every game is included **unmodified**. The original story file is stored byte-for-byte inside a small JavaScript wrapper in `games/` so the built-in interpreter can load it; the game data itself is not altered.
- ParchLock is distributed **free of charge**, with no advertising and no in-app purchases. Several of these licences forbid commercial use or charging for copies. If ParchLock is ever sold, bundled with paid software or monetised, this list must be reviewed first.
- No game here may be modified and redistributed as part of ParchLock unless its own licence allows it.
- Attribution: each entry below names the author, the licence and, where the licence requires it, a link to the licence text.
- To remove a game, delete its file from `games/` and its entry from `js/GameList.js`.

80 games are included in the release. (Development builds may still carry a larger working catalogue; the 80 listed here are the release set, and anything else is removed before a public release.) Information compiled 2026-10-05 from each game's own embedded licence or copyright text, the Interactive Fiction Database (IFDB), and the authors' official source pages. Each entry gives the game's IFID, which identifies the exact release included.
