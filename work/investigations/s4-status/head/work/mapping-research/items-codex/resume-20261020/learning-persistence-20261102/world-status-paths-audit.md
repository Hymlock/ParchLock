## Restart / RESTORE boundary

UndoRestoreSync.resync first applies pending SaveState, clears working map on restart when no sidecar handled it (35-43), calls StatTracker.Resync **before** WorldModel.tick (61-62), then resets previous topology IDs and refreshes. New-game restore-decline handling clears PL_Map_<filename> and calls StatTracker.Resync(new-game) (MapTopology:1044-1073). These are intentional live/timeline resets, not permission to erase durable module facts.

Deaths/wins are explicitly playthrough history owned by SaveState, copied through syncPlaythrough (StatTracker:1559-1566), not learned game mechanics. D243/architecture October26 supersedes old reset totals; do not apply learning persistence semantics to count all sessions together.
