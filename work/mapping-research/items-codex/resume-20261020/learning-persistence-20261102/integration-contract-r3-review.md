## Clarifications to implement literally

1. **Meaning of revised manual.** Do not interpret 'not revised' as `trigger===original`: current LearnedWords.candidates intentionally includes edited exact/allowed rows precisely when form differs from original, plus manual rows (94-104). Authored marker binds rowID+current revision+current trigger. When user changes it, old descriptor fails; the NEW current authored form may qualify by its own authored intent, never by original success evidence. Ignored row does not qualify. `commandCurrent` provides existing revision guard; do not weaken or repurpose Enter2 witnesses.

2. **Generic observation tier is remembered spelling/preference.** New arbitrary verified dictionary one-object observations can populate exact remembered forms under the chosen response policy, with threshold2 and page/submission deduplication. They do not enter allowedVerbs, VERB_FLAG calibration, D198 confirmed opcode semantics, capability/state inference or canonical synonym mapping. Keep raw outcome/provenance for diagnosis; call result remembered action spelling/preference rather than universal success. Reject probes/ambiguous/prompt-only/refusal/precondition observations with frozen response and manual revision branch precedence. This scope resolves the earlier generic-semantic-proof objection by declining that claim; it does not establish the refusal classifier universally correct.

3. **Single authority function plus final projection gates.** `exactFormsFor` presently checks threshold/dictionary/ignore but not all contextual authority. Use it as evidence input, then existing object resolution and authored/context restrictions, not an unconditional append AFTER final filters. Actionable.resolveObjectCommands has an additional outOfReach Take filter after synthesis (948); preserve it. For duplicate commands SemanticActions currently merges only specific scopes/evidence (373-405), so add marker merge only for same exact object+rendered command and revalidate it. Do not copy tier across same verb with different command.

4. **Avoid recursive Qol validation.** Validate trusted evidence against a side-effect-free authority/projection helper and the current resolved descriptor/owner restrictions; do not call OpenRadial or a provider that re-enters Qol. Payload resolution should reuse one bounded scope pool. Missing/throwing authority returns no priority marker, preserving legacy ordering. Marker validation does not itself train, persist, increment usage or mark a suggestion confirmed.

5. **More exclusion cannot be global by verb.** Build a per-current-object exact normalized command/form set from the final applicable main descriptors and filtered authoritative domain. Remove only duplicates for that item, and suppress owner-forbidden forms under the same policy. Do not ban LIGHT/DOUSE globally, suppress unrelated suggestions because another item learned them, or give dictionary suggestion a tier solely because an identically named object exists. Shared commands never inherit one member's tier.

6. **Stable module binding now; migration later.** Bind each new observation/descriptor to static executable authority and reject late foreign module/generation writes. Existing release/serial collision repair/data preservation remains separate reviewed lane; do not silently change all store keys, activate mixed legacy rows as known-owned, migrate/delete data or hash mutable VM RAM within actions/ranking. If exact provenance cannot be safely attributed under current colliding storage, fail closed for tier and retain bytes. Record how implementation handles this boundary rather than claiming all-module isolation is fixed.
