ParchLock

Adapted by Hymlock Groves. Based on Parchmap by Roy Lazarovich.

ParchLock is an awesome program built around the Parchment interactive fiction interpreter that offers some quality of life improvements such as automatic mapping, note taking, quick navigation to known rooms, and auto complete.

Key features
  • Auto mapping - ParchLock automatically builds a map of the game world as you explore it.

    Type /clear map to erase the map and start a new one starting from the room you're in.
  • Note taking - ParchLock allows you to easily add notes to remind you of tasks and interesting things in the room, these notes will appear on the map.

    Type /note locked door, look for a key; to add this note to the current room.

    Type /clear notes to erase all the notes in the current room.
  • Auto navigation - ParchLock will even calculate a route from the room you're in to a target room (if it can) based on the current state of the map.

    Type /goto kitchen; to have Parchment calculate a route from the room you're in to the kitchen and inject the instructions into the input line.
  • Auto complete - ParchLock keeps a list of words that it find in the story and will help you type less, it will even suggest room names when you use special commands that accept room names as parameters such as /goto and /room-notes.

Choose an available module to play, or open Modules to add compatible files stored on this device.

Z-machine modules receive full mapping, module-derived actions, items, and radials. Glulx modules are currently play-only.
