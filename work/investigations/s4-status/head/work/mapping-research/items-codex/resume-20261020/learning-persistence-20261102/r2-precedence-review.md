## Agreed narrow contract

A currently applicable, confirmed learned exact item/action precedes usage-only candidates for that same item. Current authority filters run first. Sort by confirmed tier, then existing usage/prior/stable order within each tier. Nonqualifying entries retain their pairwise order. No global usage persistence, item-wide promotion, global verb promotion, or capability/state inference. Knowledge persists independently of saves; current descriptors and applicability refresh.

R2 is precise on the central ordering. Qol.OpenRadial reranks before pagination (895), so comparator-level tier is necessary. Ranking only provider output or increasing confidence cannot implement it. Tools/game/history retain existing fixed ordering. This operator rule supersedes usage-first comments in Qol730/890 only for qualified item/action entries.

## Remaining narrow integration decisions

1. **Name eligibility and projection.** Define a concrete read-only authority function and marker payload: existing AttrCalibrator exactForms confirmations>=2, valid static/module key and objectID/form, current dictionary, unique verified noun, ignore/revision policy, live owner restrictions; explicitly include or exclude opcode-confirmed allowedVerbs that lack exact2, confirmed manual revision witnesses, and inspect substitute decisions. R2 alternates broad confirmed item/action wording with exact forms. Recommend first slice is exactForms only plus existing user-override rules, and name broader cases separately. Existing canonical allowedVerbs may have immediate opcode confirmation; do not accidentally demote their existing provider behavior or falsely call them exact evidence.

2. **Preserve authority at exact duplicate merges.** SemanticActions.resolveForObject deduplicates by rendered command and then verb (373-410), merging selected scope/evidence fields only. Define copying of trusted learned evidence when structural/provider command wins identical spelling. Actionable.Open currently drops descriptor metadata in final slice objects (2905); Yourself converts descriptors to {Label,Form,Enter} (43-108). Both must carry the validated marker. A raw boolean on any caller slice is insufficient. Name the full transition provider -> SemanticActions duplicate merge -> ordinary/Yourself DTO -> Qol trusted validation. Include cutover-off path if still supported.

3. **Choose main/More duplication policy.** R2 says preserve More but does not decide whether matching dictionary suggestion is removed from More or retained with learned tier. Recommend ordinary main provider owns confirmed exact action; remove the identical item/form suggestion from More. If retained, compute evidence afresh for same item and command so More does not become an alternate policy bypass. Do not infer marker from shared noun string or global usage counts. Reopened menus should retain learned action access without needing to visit More or reteach.

4. **Make manual/custom behavior explicit.** Preserve is not a comparator decision. Specify whether explicit manual edits with2 real revision witnesses qualify, whether ignored original suppresses tier as well as command, and whether custom input-wheel slices remain outside item-context precedence. Recommend custom objectless slices never qualify automatically; user preference survives under current policy. A manually revised action must not borrow the original spelling's successful evidence.

5. **Specify visual leader.** Current Qol computes unique usage leader from ranked[0].UsageCount (759), then marks rows matching that count. After tier sorting, this can crown a lower-usage learned command while ignoring actual maximum, or crown ties from lower tier inconsistently. Choose either leader reflects first eligible priority tier with unique use leader within it, or separately preserves frequency decoration using true global maximum. Recommend preferred-tier leader only, with usage fill still reporting actual usage. Update comments/meaning explicitly; this is required for correct comparator integration, not cosmetic scope expansion.

6. **Restrict intended contexts.** RankRadialCommands is also used by input radials, target submenus and other adaptive lists; all share Qol.OpenRadial. Default no trusted item evidence means exact legacy comparator. For shared-object commands require every member independently eligible or abstain; do not let item135 evidence promote an ambiguous aggregate. Target/stem/Tools/More pagination controls receive no tier. Metadata generation need not become durable; stale tap must fail through current descriptor checks.

These are finite decisions, not reasons to reopen settled native evidence. A short R3 or implementation design can resolve them without additional browser probes. No universal admission repair or legacy migration is needed to specify comparator semantics, but full symptom repair depends on the separately reviewed observation and persistence/identity lanes.
