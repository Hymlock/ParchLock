## Description

ParchLock wraps classic text adventures in a modern interface, without changing a single word of the original stories.

Type commands as you always have, or just tap. ParchLock reads the story's own game data to give you:

- **An automatic map** that draws itself as you explore, with the exits the game itself defines.
- **Tappable objects.** Things mentioned in the story are underlined; long-press one for the actions that make sense for it (open, take, wear, put in...).
- **An Equipment screen** showing what you carry and wear.
- **Notes, voice input and narration**, and a layout built for phones as well as desktop.

It ships with **75 freely licensed stories**, from the Infocom-era classics' open-source descendants to modern community favourites. Every bundled story is included under its author's licence or permission; full credits and licences are in the app and in GAMES_INCLUDED.md.

### Your own stories
ParchLock plays Z-machine stories (.z3/.z5/.z8 and Blorb). **Glulx stories (.gblorb/.ulx) are also playable, with limitations:** they run with the story text and input only, without the map, underlines or Equipment screen.

### Free and open
ParchLock is free and non-commercial. The source code is available alongside every release (ParchLock-source.zip and the GitHub repository).

### Credits
Adapted by Hymlock Groves. Based on Parchmap by Roy Lazarovich. Built on Parchment and its interpreter ecosystem (MIT). Story credits and licences: see the in-app credits.

## Install notes (Android)
- Download the APK and allow installs from your browser when Android asks.
- **Updating:** if an update looks unchanged, uninstall the old version first (Android can keep old cached files), then install the new one.
